# 同屏小屋 0.4.6 · 管理员说明

## 先创建免费私有网络

只有管理员需要操作平台网页，朋友始终使用客户端。以下依据 2026-11-04 官方文档与价格页；平台界面和免费额度可能以后调整。

1. 管理员在浏览器打开 https://central.zerotier.com ，注册或登录自己的管理员账号。
2. 首次使用时创建 Organization，例如“同屏小屋”；选择 **Personal / Free**。本次核查额度为 **10 台设备、1 个网络、1 位管理员**，适用于个人非商业使用。这里按设备计数；你和朋友的备用电脑也占额度。若界面要求绑卡、购买或试用付费套餐，先停止，不要付款。
3. 左侧选择 **Networks**。如已有默认的 `my-first-network`，可直接使用；否则选择创建网络。名称可改成自己认识的名字。
4. 确认网络为 **Private**，不要启用公开自动授权。开启私有 **IPv4 Auto-Assign**，使用 RFC1918 网段（10.x、172.16–31.x 或 192.168.x）。选择与所有朋友家庭 LAN 不重叠的网段；若客户端提示重叠，应在这里改地址池。不要添加默认路由、DNS 或公网路由。
5. 复制网络页顶部 **16 位 Network ID**。它是网络定位信息，不是密码或 API Token。可以把这个 ID 发给协助者，**不要发送平台密码、API Token、`authtoken.secret` 或设备私钥**。
6. 安装并打开同屏小屋，先完成 Windows 授权。在“我是小屋管理员”里勾选创建小屋，填昵称、头像和 Network ID，点击保存。
7. 回到平台 **Member Devices**（旧界面可能叫 Members），找到客户端显示的 **10 位 ZeroTier ID**，核对后选择 **Actions → Authorize**。管理员自己的电脑也必须批准。等客户端显示已连接。
8. 菜单“小屋 → 设备与小屋设置”可看到管理员区。复制应用生成的永久邀请码，私发给朋友。**不要把 Network ID 单独当作朋友邀请码**。

官方入门说明：https://docs.zerotier.com/start/ 。官方价格：https://www.zerotier.com/pricing/ 。不要执行官方教程中“让每位朋友再下载安装客户端”的步骤，本安装包已经包含所需组件。

## 批准朋友（每台新设备一次）

朋友填邀请码并申请后，把其显示的 ZeroTier ID 发给你。你在平台核对该 ID 后 Authorize；不要批准不认识的待审批设备。请保持管理员电脑的同屏小屋运行，朋友通过私网校验邀请并领取绑定本机公钥的应用成员证书。证书存储使用 Windows 加密存储。

首次批准完成后，管理员可以离线，其他已批准成员仍能互相创建或加入房间。房主必须保持在线。管理员上线用于新设备登记、邀请轮换、应用撤销状态发布。

## 永久邀请码、撤销与移除

- 永久邀请码没有按天失效时间，可以重复使用，但只能请求加入；**不能绕过平台设备批准**，也不是 VPN 长期密钥。
- 在客户端管理员区点击“撤销旧邀请码并生成新码”，旧码立即不能再领取应用证书；已有成员不受影响。把新码私发给后续加入者。
- 移除成员时，先记录其 ZeroTier ID，在应用管理员区“移除设备”，**再到 ZeroTier 平台 Deauthorize 或删除该节点**。后一步是网络隔离的必要操作，管理员离线时也由平台执行。
- 应用撤销列表在管理员在线时约每 30 秒同步；活动连接会进一步检查撤销。管理员离线时不能保证应用撤销立即传播，所以绝不能省略平台取消授权。
- 同一电脑重新安装但保留资料仍是同一设备。退出设备会生成新应用身份；原 ZeroTier 节点可能仍被平台记住。要强制重新审批，管理员应先在平台取消旧节点授权，再核对新的入群请求。
- 管理员电脑的私有 IPv4 建议在平台固定。若更改地址池或管理员 IP，需要生成并分发带新地址的邀请码；已离线保存的旧邀请无法自动寻址新地址。

## 管理员身份与维护

管理员签名身份在 Windows 用户资料目录的 `device-state.bin` 中，由 Windows safeStorage 保护，不能直接跨 Windows 用户复制恢复。**不要点击“退出当前设备”来普通离房**：管理员退出会丢失本机群签名身份。此测试版不提供管理员转移/恢复向导；丢失时需要建立新小屋、重新邀请并批准成员。

组件固定随包为受官方支持旧分支 **ZeroTier 1.14.2**，不是最新版本；1.16.2 Windows 整包存在不同的分发许可，不能不经复核直接替换。版本、签名、许可与驱动源码说明在 `resources\licenses` 和 `resources\network-component`。已存在的 ZeroTier 不会被本安装器降级或接管；其他版本的兼容性需要单独验证。

网络服务以 Windows 服务运行，应用使用当前用户的加密授权；新 Windows 用户需要自己的首次 UAC。房间服务只绑定已核对的私网 IPv4，UI 只绑定 127.0.0.1；不需要路由器端口映射。不要关闭防火墙。安装器增加的应用规则仅允许私有源/目标地址，媒体还必须通过客户端实际路径验证。

## 排查顺序

1. 状态“等待批准”：确认 Network ID 和 ZeroTier ID，Private 网络里批准正确节点。
2. 网络组件失败：检查 Windows 服务 `ZeroTierOneService`，重新运行完整安装包；授权失效时重新点击 Windows 授权。
3. 已批准但入群失败：管理员程序要在线；核对最新邀请码，Windows 时钟差不要超过一分钟。
4. 无私网 IPv4 或网段重叠：修正地址池；不要使用 0.0.0.0、127.x、169.254.x 或公网地址作为 overlay 地址。
5. 房间不存在/房主不可达：房主可能已离开；请重新开房发送完整新房间号。成员网络恢复后手动重连，不自动重新开始录屏或开麦。
6. 私网路径校验失败：确认双方 ZeroTier 网卡就绪，关闭冲突的其他 VPN 路由后重试；程序会阻止非私网传输，不会自动回退到公网媒体。
7. 中继卡顿：先看双方路径验证切换、实际帧率、接收速率和冻结数。分享者可选“流畅优先·允许降清”作为保底，或降低目标档位；这会降低分辨率，不代表达到默认1080p60。ZeroTier可能经免费中继，免费中继没有视频质量保证，不承诺所有校园/公司/运营商网络都可用。不要擅自购买 TURN 或服务器。

测试清单及未验证事项见 `test-report-0.4.6.md`。本说明没有要求朋友注册平台账号，也没有开通任何付费服务。

## 0.4.6 升级提示

此版仍是私网路线，管理员不用创建 Cloudflare 账号。全员覆盖安装 0.4.6 后重新开房；原审批和身份继续使用。安装器包含 Piik 原生媒体进程的私网 UDP 防火墙规则，不要只复制一个主程序 EXE 给朋友。

诊断中的 DIRECT 仅表示当时存在对应 ZeroTier 节点的活动直连路径，不是持续吞吐保证。无活动直连路径不能自动判定一定在走中继。若只有画面慢，分别查看原生实际帧率、码率、两端网络和底层路径。
