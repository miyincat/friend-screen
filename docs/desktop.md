# 同屏小屋 Windows 客户端

这是独立开发的 Windows x64 客户端本地测试版。它不是 Oopz 插件，不需要 Oopz 账号，也不能加入 Oopz 房间。

## 启动

双击完整发行目录里的 `FriendScreen.exe`。没有安装器、不需要管理员权限；请保留旁边的 DLL、resources、locales 等文件，不要只拷贝一个 EXE。朋友收到压缩包后要先完整解压，再启动。

本测试版没有商业代码签名。系统可能显示未知发布者；发布给更多人前需要完成签名及正式发布流程。不要随意关闭系统安全防护。

## 现在：本机体验

在启动页选择“本机体验”，客户端会在本机启动临时房间服务，地址只监听 127.0.0.1，端口随机。网页里的创建、加入、共享和麦克风按钮与浏览器版相同。

使用“小屋 → 复制本机服务地址”，粘贴到同一台电脑的浏览器，可用浏览器充当第二名成员验证观看效果。本机模式不是公网服务，邀请链接不能供异地朋友访问；关闭客户端会关闭这个本机服务。

点击开始共享后，客户端弹出自己的屏幕/窗口选择器，必须选中一项后确认。系统声音默认不勾选。在 Windows 上，启用系统声音可能包含其他应用的声音，并不保证仅捕获所选窗口的音频。涉及私人通知或其他通话时请关闭该选项。

麦克风需要单独开启；默认关闭。闭麦、离开或断开房间会停止麦克风采集；停止共享仅停止画面和共享声音，语音继续。回到服务器设置会退出当前页面和共享。

## 以后：连接自己的域名

域名购买后，还要部署房间服务器、可信 HTTPS 和可用 TURN 中继。仅买域名本身不会提供媒体中继能力。完成 `docs/deployment.md` 中的部署后，在启动页输入你自己的完整 HTTPS 服务地址，例如 `https://screen.your-domain.example`。

所有朋友填写同一个服务地址，再用站点口令和房间口令加入。客户端记住服务地址，并在勾选“记住登录”时保留最长 30 天的登录状态；不保存账号明文密码、站点口令、房间口令或录制文件。只连接你信任并管理的服务器：它提供网页代码和房间信令。

菜单里的“小屋 → 连接设置”可更改地址。外部导航、新窗口、摄像头和与功能无关的权限均受限制；页面没有 Node.js 或任意本地文件访问权限。

## 当前范围

- 最多 6 人，一次一个人共享，可同时语音。
- 720p30 / 1080p30 / 1080p60 为目标档位，不是性能承诺。
- Windows 屏幕/窗口采集效果需以你要分享的应用为准；受保护内容可能黑屏，不绕过保护。
- 支持注册、登录、自动登录、修改昵称与头像；暂不包含找回密码、自动更新、主持人踢人、聊天记录或大规模媒体转发功能。
- 本次交付不含域名购买、公网部署、代码签名或跨网络性能承诺。

## 源代码开发

需要 Node.js 22.12+：

```text
npm ci
node node_modules/electron/install.js
npm run desktop
npm run pack:win
```

打包输出为 `dist/0.2.0/FriendScreen-win32-x64`。为避免误覆盖，已存在的发行目录不会自动删除；需要重新打包时，请先自行重命名保留旧版本。服务器可以用同一项目的 `npm start` 独立运行。

## 0.2.0：账号、头像与语音

- 首页左上角点击“登录”，第一次使用选择“注册账号”。账号为 3–32 位字母、数字或下划线，密码为 8–128 位，昵称最多 24 个字符。
- “记住登录”默认勾选，有效期 30 天。下次打开会连接上次使用的服务并恢复账号；屏幕和麦克风仍默认关闭。退出账号会退出房间并撤销本次登录。不勾选时，关闭客户端后需要重新登录。
- 点击“修改头像与昵称”可上传 PNG/JPG/WebP 图片（最大 5 MB），自动裁成 128×128 方形头像。资料会同步给当前房间和之后加入的朋友，也可恢复默认头像。
- 展开“麦克风与发送音量”，在房间中开麦或闭麦；自己的发送音量为 0–200%，登录后随账号保存。0% 只静音发送，闭麦释放设备。200% 可能使过大声音失真，建议从 100% 调整。
- 每位朋友下方的“本地收听”滑块独立调整 0–200%，也可单独静音并恢复。仅影响你听到的声音，不会操作对方的麦克风；这些数值只在当前房间会话中保留。先点击“打开声音”才能收听。屏幕共享声音不受朋友的麦克风滑块影响。
- 本机模式的账号数据位于 Windows 应用数据目录中“同屏小屋/local-accounts”；本机账号不自动同步到未来的域名服务器。朋友异地使用时，所有客户端应连接同一台 HTTPS 服务器。
- 服务端用加盐密码哈希校验密码，登录凭据为有期限的会话 Cookie。此版本适用于受邀请的小群组，账号服务使用单进程文件存储，公网部署前需配置 HTTPS、站点口令和持久数据目录。
