# 同屏小屋 0.4.6 · 朋友使用说明

这是 Windows 10/11 x64 私网测试版。你只需安装一个安装包，不用另装或登录 ZeroTier，也不用浏览器。先向小屋管理员领取完整的 `FSI1.` 开头邀请码。

1. **安装**：双击 `FriendScreen-0.4.6-Setup-x64.exe`。安装包含 ZeroTier 系统服务和签名网卡驱动，需要 Windows 管理员权限。出现 UAC 时核对是你刚启动的安装程序再允许。此测试版应用安装器未签名，可能被 SmartScreen 或杀毒软件拦截；先向发送者核对文件 SHA-256，不要关闭杀毒、防火墙或驱动签名保护。若不愿运行未签名程序，请停止安装。
2. **首次设置**：桌面打开“同屏小屋”，点击“首次 Windows 授权”，这会再出现一次 UAC，用于把本机网络控制凭证加密保存给当前 Windows 用户。输入昵称、选择头像、粘贴邀请码，点击“保存并申请加入”。
3. **等待批准**：把页面显示的 **10 位 ZeroTier ID** 发给管理员核对。管理员在后台批准一次，并保持自己的同屏小屋运行。显示“已连接”后进入小屋。此后的启动会自动恢复设备身份，无账号、密码或注册流程。
4. **创建或加入**：任何人都可点“创建房间”，把完整的 `FSR1-` 开头房间号发给朋友。加入者点“加入房间”后粘贴完整房间号。不要把邀请码当成房间号。最多 8 人；房主离开房间、退出程序或关机后房间结束。网络中断后采集停止，恢复网络后可以重新粘贴房间号加入仍在线的房主。
5. **共享与声音**：进房后会请求麦克风授权，并开启收听；拒绝麦克风仍可观看。点“开始共享”选择整个屏幕或某个窗口，并选择显卡编码器；需要共享系统声音时在选择器勾选，默认不勾选。系统音频可能包含电脑上其他应用声音，建议使用耳机。一次只能一人共享，默认目标为 1080p / 60 帧；查看连接详情中的实际编码/解码帧率确认是否达到。受网络和设备限制时可能达不到60帧。
6. **音量与资料**：“麦克风与发送音量”调整自己 0–200%；“闭麦”停止采集。成员下面的滑块和静音只改变你自己的收听，不影响别人。头像和昵称在“修改头像与昵称”更新。菜单“小屋 → 设备与小屋设置”可查看网络状态。退出当前设备会清除本应用设备身份，下次需重新审批；只想离房请用“离开房间”。

**连接失败**：展开“查看连接诊断”，把双方显示的完整一行发给管理员。0.3.6 会显示本机 ICE 候选发送数、过滤数、对端候选收到/应用数和 SDP 收发数；不要为了试通而关闭防火墙或放宽私网校验。确认房主在线、房间号完整、设备获批；管理员检查双方 ZeroTier 网络状态和私有 IPv4 分配。公司/校园网或受限 UDP 网络可能无法直连；如需测试保底，可主动选择“流畅优先·允许降清”，但分辨率会降低。不能保证所有网络都能通，不需要也不应购买页面提示的套餐。

**日志**：菜单“小屋 → 打开日志目录”。安装日志在 `C:\ProgramData\FriendScreen\logs`。应用不记录完整邀请码、密钥或媒体，不设置业务遥测；ZeroTier 服务有其正常的网络控制与加密转发通信。

**卸载**：先在应用里退出当前设备，再通过 Windows“已安装的应用”卸载。应用会移除自己的防火墙规则；预先存在的 ZeroTier，或仍加入任何网络的组件，会保留以免影响其他软件。若组件被保留，可确认无人使用后在 Windows 中手动卸载。资料与日志默认保留；旧 v0.2.0 未被删除。

当前跨网络和 7 台真实电脑的验收状态请看随包《测试报告》，本机回归通过不代表这些测试已通过。

## 0.3.6 原生画质与连接

已有身份的实际覆盖迁移尚未验证。升级时保留原安装位置和资料；如提示资料无法解密，请停止操作并联系管理员，不要退出设备、删除资料或重建小屋。

双方都需升级到 0.4.6；覆盖安装即可，不要退出设备或重建私网。默认目标 1080p60、保持分辨率、单路视频目标 6 Mbps、总上传预算 8 Mbps。可在房间的「分享设置」选择 2K，或细调分辨率、帧率和码率。点「开始共享」后先选缩略图，再确认共享。观看端不能修改分享者的发送画质；请看实际接收尺寸和帧率。网络不足时可能降清或降帧，提高到 20 Mbps 也不会提升宽带真实上行。

视频现在由 Piik 原生采集编码，并可由房间内成员转发。任何成员仍可共享，一次一人。转发成员退出时可能短暂停顿后恢复。

连接详情新增 ZeroTier 底层信息：DIRECT 表示活动直连路径可用；“未检测到直连”可能是中继，也可能尚未连通；“未知”表示没读到证据。不能仅凭“私有网卡已验证”判断是否经过中继。

## 0.3.10 原生视频诊断
你和朋友同时打开“小屋 → 诊断记录窗口”或按 Ctrl+Shift+D，点击“开始记录”。问题出现时选择类型并点“标记问题”，继续运行 20—30 秒后停止。桌面会生成可直接发送的诊断 ZIP，请双方各发一份并说明谁是分享者。详细说明见 diagnostics-guide.md。

0.3.10 可分开记录对外视频入口、本机播放、发送队列和共享声音。画面卡住但共享内容的声音仍正常时，选择「画面卡顿，声音正常」标记。本版修正本机播放排队和 H.264 乱序组帧；异地效果仍需双方复测。

## 0.3.10 流畅观看和上传预算

约 11 Mbps 上行可先使用默认 8 Mbps 上传预算。直接下游有两人时，应用将视频目标分成每路 3 Mbps，并留出声音与补包余量；调高单路目标不会突破此预算分配，也不会提高宽带真实速度。观看者兼任转发时，也按自己的上行选择预算。

“本机观看方式”默认流畅观看，给视频和共享声音增加适度缓冲；需要更快互动可切到实时观看。两种方式都不改变独立麦克风聊天的缓冲。切换立即生效，上传预算和观看方式在本机保存。

保持分辨率可避免低码率表示自动减半，但带宽不足时仍可能模糊或降帧。需要帧率优先时可选择“流畅优先·允许降清”。本版不使用 CDN，不承诺 6 Mbps 固定达到 2K 或 1080p60。
