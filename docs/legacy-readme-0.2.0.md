# 同屏小屋

为几位朋友制作的独立屏幕共享原型：最多 6 人，一次 1 人共享屏幕，所有人可自愿开麦。中文网页，无需 Oopz 账号，不连接 Oopz 服务。

## Windows 客户端（优先入口）

已生成 `dist/FriendScreen-win32-x64/FriendScreen.exe`。双击运行，选择本机试用；以后部署好自己的 HTTPS 域名和 TURN 后，在启动页填写服务器地址。

朋友使用时应复制完整发行目录或完整解压便携包，不需要安装 Node.js。系统声音在客户端选择器中默认关闭，Windows 开启后可能包含其他应用音频。客户端为未签名本地测试版。

详细说明见 `docs/desktop.md`，验证记录见 `docs/verification.md`。源码运行：`npm run desktop`；重新构建：`npm run pack:win`。Electron 45 的二进制如未安装，先执行 `node node_modules/electron/install.js`。

## 在这台电脑试用

1. 双击 `start-local.cmd`，保持窗口运行。本机已安装所需 Node.js。
2. 用桌面 Edge 或 Chrome 打开 `http://localhost:8787`。
3. 输入昵称、创建房间，把房间号与房间口令填入另一个浏览器窗口，验证加入。
4. 点击共享，浏览器会要求选择标签页、窗口或整个屏幕。选中希望分享的内容并确认。
5. 想共享声音时，勾选浏览器选择框中的共享音频；若选择源或浏览器不支持音频，仍可分享画面。开麦须另行点击并授权。佩戴耳机可避免回声。
6. 点击停止共享或浏览器原生的停止按钮；离开房间也会关闭本地媒体。最后一人离开后，房间删除。

**`localhost` 只代表当前电脑，不能把这个地址发给异地朋友直接使用。** 默认服务只监听 `127.0.0.1`，没有启用公网访问或第三方 STUN/TURN。异地使用见 `docs/deployment.md`，还需要你自己的域名/服务器/可用中继，当前没有替你购买、部署或对外公开。

命令行方式：

```powershell
npm.cmd ci
npm.cmd start
```

源代码开发需要 Node.js 22.12+，推荐现有 Node.js 24。服务器生产环境 `npm ci --omit=dev`；服务器只有一个运行时依赖 `ws`。已打包客户端不需要另外安装 Node.js。

## 已实现

- 随机房间号、随机建议口令、昵称、最多 6 人、成员和麦克风状态。
- 屏幕/窗口/标签页选择（具体选项由浏览器提供）、本地静音预览、远端观看和全屏。
- 720p30、1080p30、1080p60 目标档位；实际分辨率和帧率取决于采集源、设备、带宽和浏览器。
- 可选屏幕声音、独立麦克风语音、手动启用远端播放。
- 通过 WebRTC 传输媒体，房间服务仅转发会话信令；可配置自有 TURN 中继。
- 邀请链接不含房间口令，需单独发给朋友；不在 localStorage 保存口令。
- 停止/离开/断开信令时关闭本地媒体，禁止无提示重新捕获。

## 隐私与范围

- 默认不开麦，没有摄像头、录制、后台采集或分析统计功能。分享必须由你主动触发，并通过浏览器选择和授权。
- 房间状态在服务端内存中，重启即失效；只保留加盐 scrypt 房间口令摘要，服务器不记录口令或媒体。
- HTTPS 部署时信令加密；WebRTC 使用浏览器的媒体传输加密机制。仍需信任提供网页和信令的管理员，房间口令不是经独立审计的身份认证系统。
- P2P 可能向同房间成员暴露连接地址；需要减少此暴露可设置 `ICE_RELAY_ONLY=true`，这需要真实可用 TURN，且会增加中继流量。
- 邀请了谁，谁就能看到/听到你分享的内容，并可能使用自己的工具录制；只分享有权分享的画面和音频。
- 这是可运行原型，不具备商业级抗滥用、账号管理、主持人踢人或大规模媒体转发。公网配置增加站点口令以限制陌生人使用。

浏览器测试使用本机 Edge（或设置 `BROWSER_PATH`）。基础测试用合成画面/声音；原生采集测试只选专门创建的浏览器标签页或测试窗口，不捕获你的私人桌面。详细执行结果和未验证范围见 `docs/verification.md`。

原始观察及实现边界见 `docs/analysis.md`。本项目未使用 Oopz 业务代码、DLL、图片或私有服务。


## 0.2.0 账号与语音控制

首页支持注册/登录与 30 天记住登录、昵称和头像修改、独立的麦克风发送音量和每位朋友的本地收听音量（0–200%）。保留游客模式。登录本身不会开始采集。

新增验证：`npm run test:profile` 测量真实 WebRTC 接收音频幅度并验证头像同步；`npm run test:account-desktop` 验证整个客户端关闭、重启后的账号/头像/音量恢复、退出撤销和不记住登录。

账号存储默认在 `data/accounts.json`，可用 `ACCOUNT_DATA_DIR` 指定持久目录；测试可以用 `:memory:`。该目录包含密码哈希和会话哈希，不应提交、打包或开放 Web 访问。客户端本机模式独立保存到应用 userData 内。当前单进程存储不支持多实例并发写同一目录，无邮件验证或密码找回；本机账号与未来公网服务器账号相互独立。
