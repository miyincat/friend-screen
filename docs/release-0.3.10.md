# 同屏小屋 0.3.10 · 私网流畅观看测试版

保留原有私有房间、ZeroTier 准入、昵称头像、独立麦克风和压缩媒体转发。借鉴直播播放器允许适度缓冲的做法，新增“流畅观看”和“实时观看”，并处理多人观看时的上行分配。

- 默认“流畅观看”：为本机视频及共享声音请求 600 ms 接收缓冲目标。实际延迟由播放器和网络决定，不等于固定增加 600 ms，也不是秒级直播缓存。可以随时切回“实时观看”，不重启共享。麦克风聊天使用独立连接，分享者本机预览维持自动缓冲。
- 单路视频目标默认 6 Mbps，总上传预算默认 8 Mbps。预算的 75% 分给本机的最多两路下游视频，余量用于声音、封装和补包。例如 8 Mbps 预算、一位直接观看者时单路上限 6 Mbps；两位直接观看者时每路 3 Mbps。观众在房间中的转发位置决定直接下游数。这是编码目标分配，实际线速仍受拥塞控制、补包等影响，不是流量硬限速。
- 默认选择“保持分辨率”。仅在此偏好下，原生编码的低码率表示也保留目标尺寸，避免因选择低表示就固定减半到 540p。平衡和流畅优先仍可降分辨率。相同像素尺寸不代表相同清晰度；高速运动、低码率或差网络仍可能模糊、降帧或停顿。
- 诊断窗口及导出增加观看方式、缓冲目标、上传预算与有效单路编码上限。继续区分原生链路、浏览器播放和麦克风统计，不记录媒体内容。
- 修正浏览器隐藏候选 IP 时的路径误判。对明确的隐私占位值，只有当前选中链路统计中的双端私网地址均已验证、且双方 UDP 端口与实时接口一致，才允许继续；证据不足仍暂停，真实地址冲突仍拒绝。Chromium 的隐藏行为见 [上游实现](https://webrtc.googlesource.com/src.git/+/021f96f5462db3658bdbd3be5ebff2ca43acc9ae/p2p/base/p2p_transport_channel.cc)。

两端建议同时升级，覆盖原安装位置并保留设备资料。原 0.3.9 安装包和源码保留在原目录。本版不需要新建私网或购买服务器；未加入 CDN、直播平台账号、公网回退或付费服务。它不能保证在 6 Mbps 下达到 B 站 2K 直播的画质和稳定性。

使用 Node 24.22.1、Electron 45.2.2、Go 1.27.3。原生源码保留在 vendor/piik-source；CGO_ENABLED=0，go build -trimpath -ldflags "-s -w" ./cmd/piik-app。Windows 原生采集辅助程序沿用原版。实际验证范围和指标见 test-report-0.3.10.md。
