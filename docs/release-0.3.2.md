# 同屏小屋 0.3.2 私网测试版

本版为跨网络排查补充 ICE 连接诊断：每位朋友的连接行显示本机候选生成/发送/过滤数量、收到并应用的对端候选数量，以及 SDP 收发数量。计数不显示 IP 地址或凭证。

为保护私网边界，候选规则没有放宽：仅接受与本机已分配 ZeroTier 地址相符的 UDP host 候选，建立连接后仍验证实际媒体路径。若双方没有可用的 overlay 候选，客户端不会退回公网或普通局域网路径。

本版修复前置早到信令缓存的变更保留。浏览器回归仍使用真实 `RTCPeerConnection` 和合成媒体，不等于真实两台电脑的 ZeroTier 验收。

## 验证

- `npm test`：19 项通过。
- `npm run test:network`：11 项通过。
- `npm run test:browser`：11 项通过，覆盖候选诊断、信令乱序、视频帧和音频 RTP。
- 两台真实电脑的 ZeroTier 媒体、真实麦克风/系统声音、干净 Windows 安装升级和卸载：未验证。

## 回滚

两台电脑都退出应用后，可重新安装 0.3.1。客户端身份和私有网络配置保存在用户资料目录，常规覆盖安装不会删除；不要选择“退出当前设备”来回滚。

本项目独立实现，不包含 Oopz 代码、资源、协议或服务。安装器未签名，安装 ZeroTier 系统服务和网卡驱动需要 UAC。
