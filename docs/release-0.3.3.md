# 同屏小屋 0.3.3 私网修复测试版

本版修复已在当前电脑复现的 ICE 候选缺失：旧的 Electron 权限检查始终拒绝媒体状态查询，导致 Chromium 只产生默认网卡候选，未枚举已启用的 ZeroTier 网卡。普通网卡候选被应用既有的私网规则正确过滤，于是 SDP 已交换但 ICE 一直未开始，画面、共享声音和麦克风都无法传输。

最小修复仅允许当前受信房间主页面的音频权限状态检查，使 Chromium 能枚举非默认私网网卡。真实麦克风采集仍必须经过原来的确认对话框；摄像头继续拒绝，屏幕共享仍需主动选择。没有修改用户的 ZeroTier 网段、地址或授权。

私网边界未放宽：只发送/接收指定 ZeroTier IPv4 的 UDP host 候选，保留 SDP 清理和实际选中媒体路径校验；没有新增 STUN、TURN、公网媒体入口或付费服务。0.3.1 的早到信令队列及 0.3.2 的候选诊断继续保留。

## 更新方法

双方都退出旧客户端，覆盖安装 0.3.3 后重新开房和加入。不要点击“退出当前设备”，也不要删除用户资料；常规覆盖安装保留设备身份、头像、昵称及私网设置。房间里至少两人时再检查“本机发送”“对端收到”，正常应均有大于零的可用候选，并最终显示“私有网卡（已验证）”。

本机复现已确认修改后出现 ZeroTier UDP host 候选。真实两台电脑在不同网络的媒体传输、真实麦克风/系统声音以及 6–7 台设备稳定性仍需用户双方复测，不能以本机回归替代。详细结果见 test-report-0.3.3.md。

## 回滚

退出应用后重新运行保留的 0.3.2 安装包可回滚；但其网卡枚举缺陷仍存在。源码旧版副本保存在 artifacts/rollback-0.3.2，0.3.2 发行目录未覆盖。

独立实现，不含 Oopz 代码、素材、协议或服务。安装器未签名，Windows SmartScreen 可能提示；网络驱动/系统服务的安装需要 UAC。
