# 同屏小屋 0.3.8 · 原生视频诊断

这是一版用于定位间歇掉帧的诊断增强版，不是已验证的卡顿修复。画质档位、码率、自适应策略、ZeroTier 私网约束、身份格式及房间行为保持现有设置。

新增对外视频入口、RTX 修复、乱序/缺包、媒体 RTT、发送队列积压/丢弃/等待时间及本机完整帧恢复统计。监视窗口明确分开对外视频、本机播放和房间语音；共享内容声音单独记录。新增「画面卡顿，声音正常」问题标记。

沿用「小屋 → 诊断记录窗口」或 Ctrl+Shift+D。双方都安装此版本后开始记录；复现问题并标记，继续 20—30 秒，再停止保存桌面 ZIP。具体步骤和字段解释见 diagnostics-guide.md。

原生组件由随附的修改源码重新编译。Piik 上游仍为 v2.5.3，控制协议使用兼容的数值统计扩展，不新增公网服务、不上传日志、不改变私网绑定。Windows 采集 helper 未修改。日志仍不包含音视频内容、IP、完整房间号、邀请码、口令或长期密钥。

保留 0.3.7 桌面安装包和源码归档。源代码回滚基线为 a8d115212fbdb4caa5a518c223751ff8acff4ce0。本次没有改用户身份或入网凭证；升级无需重新创建 ZeroTier 网络或重新入网。旧身份覆盖安装仍需现场验证，遇到身份错误不要退出设备或清空数据。

安装包仍为未签名 Windows 10/11 x64 测试版。包含的网络服务/驱动需要管理员权限（UAC）；SmartScreen 或安全软件可能提示。检查发行来源与文件哈希，不建议关闭系统防护。

测试范围见 test-report-0.3.8.md。真实双方跨网掉帧原因及 7 台物理机器性能未验证，不能根据本机测试宣称已经解决。
