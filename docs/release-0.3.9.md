# 同屏小屋 0.3.9 · H.264 乱序恢复与本机播放修复

针对第三轮日志中持续有视频流量、共享声音正常但画面反复降到个位数帧的问题，本版修改两处播放路径：

1. 对本机播放器的原生视频转交使用现有库的直通发送器，取消套用在本机连接上的宽带估计、定时排队和带宽探测。跨电脑连接继续使用原有发送节奏与拥塞控制。RTCP、RTX 修复、容量边界、关闭清理和私网绑定保留。
2. 在固定的 Electron 45.2.2 中启用内置 WebRTC H26xPacketBuffer，替换本应用的默认 H.264 组帧路径。受控测试已表明旧路径遇到少量乱序会严重掉帧，而新路径能恢复连续组帧。生产启动与测试客户端共用 desktop/media-runtime.cjs，避免只在测试环境生效。

不改现有画质档位、码率上限、编码器选择、昵称头像、麦克风音量、房间寻址或 ZeroTier 凭证。不新增服务器、域名、付费服务或公网媒体回退。诊断窗口保留，可看到“本机直通”与“网络节奏控制”；它们描述发送方式，不是 ZeroTier 底层 DIRECT 状态。

双方都升级到 0.3.9 后复测。保留原安装目录和设备资料，不要退出当前设备或重建网络。打开 Ctrl+Shift+D 开始记录；画面卡但共享声音正常时使用相应问题标记。停止后发送双方新生成的诊断 ZIP。

本机受控测试不是两台真实异地电脑验收，详见 test-report-0.3.9.md。未承诺所有网络都能固定达到 1080p60。尤其在不具备足够带宽、CPU/GPU 或内存的情况下，原有自动适应仍可能降档。

Electron 的组帧开关依赖当前固定运行时；将来升级 Electron 时须重新跑丢包、乱序和正常链路测试。本轮临时逐包调查探针已从产品代码删除；正式版本不会保存 RTP 包或音视频内容。

旧版安装包与源码继续保留在桌面“同屏小屋-0.3.8”，可用于回滚。本安装包仍为未签名 Windows x64 测试版，网络组件安装需要 UAC。
