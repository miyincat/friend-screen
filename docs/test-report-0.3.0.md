## 单机 7 客户端基线

一台 16 逻辑处理器 Windows 11 电脑，7 个独立 Edge 上下文；合成 1280×720 / 30 帧画布和振荡器音频，7 人开启合成麦克风，一路屏幕同时发送给 6 人；通过 loopback WebRTC mesh。持续 601.99 秒，每 10 秒记录一次，共 60 个样本。全部样本每人保持 6 个连接，所有接收端每个采样间隔的解码帧数持续增长，0 个停滞间隔、0 个页面错误或崩溃。

- 6 个接收端平均约 29.38 帧/秒。
- 分享端平均 RTP 发送约 3.12 Mbps；所有客户端合计约 4.29 Mbps。画布场景简单，此结果不能用于推算真实桌面或游戏所需上行；没有计入 ZeroTier、重传和链路封装。
- 浏览器全部进程的 CPU 平均约 4.81 个逻辑核，相当于本机 16 逻辑核总容量的 30.06%；不是一台远端客户端的 CPU 占用。
- 原始数据：`artifacts/overlay-tests/seven-client-loopback.json`；统计与连续解码验证：`seven-client-summary.json`；截图：`seven-client-loopback.png`。
