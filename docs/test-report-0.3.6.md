# 同屏小屋 0.3.6 测试报告

日期：2026-11-05（北京时间）。

## 测试环境

Windows 11 专业版 10.0.26200；Intel i7-13620H，16 个逻辑处理器，16 GB 内存；NVIDIA GeForce RTX 5070 Laptop GPU / Intel UHD Graphics。Electron 45.2.2，Node 24.21.0，基于 Piik 2.5.3 的私网修改构建。使用已存在的 ZeroTier IPv4 网卡。

多个 Electron 客户端、Piik 媒体进程和测试窗口都在同一台电脑，身份审批在多人测试中明确模拟；媒体实际绑定本机 ZeroTier 私网地址。没有把同机测试当作异地通信。画面是自建动画窗口，声音是合成音，没有采集真实桌面内容或物理麦克风。

## 已验证

- 原服务回归 19 项、私网与路径回归 43 项通过。覆盖设备签名、重放/撤销、8 人上限、错误房号、重名、单路共享、非法公网媒体候选与越权路由拒绝。
- 原生 Go 私网绑定与输入拒绝测试通过；四客户端端到端回归 11 项通过。
- 7 个独立客户端同房，持续共享至少 600 秒。接收尺寸为 1920×1078；窗口客户区/采集边界使高度略低于目标，不虚报为精确 1080。
- 排除最初 10 个采样后的 UI 实测帧率：最低 58.3、中位 60.0、最高 60.3 帧；接收平均约 4.94 Mbps。没有发现连续一秒采样间解码帧数停滞或回退。
- 实际检查到 19 个原生 UDP 套接字，全部只绑定指定 ZeroTier IPv4；无 0.0.0.0、:: 或物理网卡监听。已关闭不需要的 mDNS 监听。
- 合成来源声音通过原生采集、二层转发和本机播放器，接收音频波形非零。合成麦克风 0/100/200% 与每位朋友的独立音量、静音真实生效，闭麦释放音轨。
- 转发成员退出后下游重新连通并继续播放；普通成员可接替共享；房主离开关闭房间；原观看者可另开房间。
- 首次设置桌面回归通过：错误邀请码拒绝、Windows 加密存储、重启设备 ID 保持、管理员 Network ID 格式检查。

7 客户端及其媒体/渲染进程在同机运行的合计平均 CPU 约 24.0%，工作集加总峰值约 5.42 GiB。该工作集加总可能重复计算共享页；不是单个客户端占用，也不是实际游戏负载。统计窗口约 582 秒。

## 打包程序核验

打包 EXE 已通过 5 项核验：使用打包程序自己加密的新合成身份和现有获批 ZeroTier 网卡进入小屋；真实协调器和签名认证创建房间；来源声音默认关闭；随包原生媒体采集、编码并播放；停止共享及离房清理。测试窗口实际 1920×1078，5 秒观察到 301 帧。包内 39 项文件一致性校验通过。

旧用户加密资料复制到临时目录后未能通过 safeStorage 解密，该测试在启动阶段超时。没有修改生产加密方法，也没有覆盖原资料。随后新身份的打包验证通过，不等于原用户身份覆盖升级已通过；真实旧身份迁移仍未验证。应用存储格式未改，升级时保留原路径与资料；若提示资料无法解密，不要退出设备或重建小屋，先回滚并检查原资料。

## 未验证

两台不同网络的实体电脑、7 台实体电脑、真实游戏负载、实际 ZeroTier 中继质量、物理麦克风听感与回声消除、多个真实程序的系统混音、干净 Windows 10/11 安装/UAC/卸载均未验证。当前升级包未自动覆盖本机旧安装版。未签名安装器可能触发 SmartScreen；不要关闭系统防护。

1080p60 是目标，不是任何网络的保证。新版本减少分享者重复上传和浏览器采集编码负担，但不能增加宽带上传、消除运营商丢包或保证 ZeroTier 直连。
