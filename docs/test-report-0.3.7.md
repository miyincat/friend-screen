# 同屏小屋 0.3.7 验证范围

日期：2026-11-05。Windows 11 x64，Electron 45.2.2、Node 24.21.0；原有私网媒体二进制沿用 0.3.6。

## 已通过

- 诊断模块 6 项测试：字段白名单、标识摘要、真实 ZIP 读回、开关停止写入、开始/关闭并发、容量自动停止、异常结束恢复打包、桌面不可写与目录越界拒绝。
- 两个独立 Electron 客户端在同一台 Windows 上使用已存在的 ZeroTier IPv4，运行真实原生视频和合成语音。诊断窗口显示帧率、码率、语音与进程资源；问题标记进入文件。
- 手动停止自动生成 ZIP；关闭开关后文件不再增长；原生关闭窗口自动保存；退出程序自动完成导出；双方 roomTag 可关联。
- ZIP 内容检查未发现完整房号、实际 IP 或窗口标题。图像和音频不进入日志；日志中的媒体统计均为数值。
- 原服务回归 19 项与私网/路径回归 43 项通过。

证据：artifacts/diagnostics-0.3.7/results.json、live-window.png。测试目录中的 test-desktop 是隔离的模拟桌面输出，未当作真实跨网测试。打包程序的实际桌面导出结果以 artifacts/diagnostics-packaged-0.3.7/results.json 为准。

## 打包版核验

打包 EXE 已完成三项检查：菜单可打开独立诊断窗口且默认关闭；实际 Windows 桌面生成 ZIP，包内 fflate 压缩/解压正常；资源采样、问题标记和摘要内容正确。生成了一份约 4 KiB、时长约 7 秒的安装包验证记录，位于桌面，用于确认真实输出路径。正式跨网排障需另开一轮记录。

46 项包内文件一致性校验通过。证据为 artifacts/diagnostics-packaged-0.3.7/results.json 与 window.png；这不是安装器实际安装或旧身份迁移测试。

## 未验证或不能据此推断

两台异地电脑的实际共享、真实游戏负载、GPU 利用率/显存、每条原生视频网络路径的完整 RTT/丢包、干净系统安装/UAC/卸载、旧用户身份的实际覆盖迁移均未验证。媒体二进制沿用 0.3.6，但没有把该版的 7 客户端 10 分钟测试重复标成 0.3.7 新测试。

诊断只能帮助缩小问题范围，不保证仅凭一次记录就能断定唯一原因。最好双方同时记录，并在问题出现时标记。窗口关闭/退出的测试使用原生窗口关闭事件；网页脚本的 window.close 不等同于用户点窗口关闭按钮。
