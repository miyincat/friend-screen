# 同屏小屋 0.3.8 验证范围

日期：2026-11-05。环境：当前 Windows 11 x64 电脑；Electron 45.2.2、Node 24.21.0、Go 1.27.3。私网原生媒体重新编译；采集 helper 沿用原文件。

## 开发态已验证

- Go：真实 Pion 连接模拟包丢失和延迟 RTX 修复，验证原生入口读包、NACK、RTX、修复后缺包计数；发送侧真实丢弃/重传缓存命中进入诊断。
- Go：队列积压、最老等待、最长等待、队列满丢弃、失败写入、关闭清理；迟到修复导致缺包下降，重复包和乱序分开；缺失 RTT 不伪造为零；已有私网限制/质量分配检查通过。
- Node：诊断白名单、脱敏、真实 ZIP 读回、关闭停止写入、异常导出、容量上限、原生快照/事件、共享声音分离、过期与连接关闭清理、完整帧/关键帧字段检查通过。
- 两个隔离 Electron 客户端使用已有 ZeroTier IPv4、真实原生视频、合成麦克风与测试窗口声音。新监视窗口实际显示对外入口、本机播放、视频 RTT、队列、共享声音、完整帧和关键帧。
- 实际 ZIP 中发送/接收端同一视频边摘要一致；本机播放 sourceEdgeTag 对应上游边；发送端 RTCP RTT 和成功发包非空，接收端原生视频与共享声音计数递增。
- 停止记录后不再写入；关闭窗口和正常退出完成导出；两侧导出未发现真实 IP、完整房号、窗口标题等禁记内容。已检查监视窗口截图。

证据：artifacts/diagnostics-0.3.8/results.json、live-window.png，以及该目录的 host/viewer 隔离 test-desktop 日志。它们是自测资料，不是用户的正式跨网故障日志。

## 未验证与限制

本轮未完成两台不同网络电脑的新版本复测、真实游戏负载、实际听感、7 台物理机器、干净 Windows 10/11 安装/UAC/卸载、旧用户身份的覆盖迁移。未改变媒体调度策略，也未宣称修复卡顿。两人本机模拟只验证采集链和数据口径，不能代表跨网性能。

原生帧尾计数不是完整帧数；完整帧和解码/冻结位于浏览器播放统计。浏览器未提供的字段保持 null。音频收包不证明实际听见声音。样本时钟可能有误差，分析须检查新鲜度、流标识和计数重置。
