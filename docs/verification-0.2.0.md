## 媒体连接修复

双方同时预建 transceiver 在协商碰撞时可能变成六个媒体段，造成麦克风误归到共享音轨。改为由初始发起方建立三个媒体段，接收方沿用收到的媒体通道。现有与新增媒体测试均通过。
